## UI design

The goal of the UI is to pack as much information in as small of a space as possible. This is meant to be a productivity tool. The default window size is 1100px by 700px, which is _pretty_ small, so I have to think of ways to be efficient.

### Top bar

Right now the window bar is the default MacOS one, but I plan to replace this for all operating systems. It can hold important information about the current screen, such as course title for example. I'm also planning to move the bottom bar's folder view to the top, to free up the bar for hints as to what actions can be performed on the currently selected item.

Assignments and material view are in desparate need of this.
