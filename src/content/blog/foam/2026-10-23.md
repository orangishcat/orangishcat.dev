### Onboarding

![[./Attachments/Pasted image 20261023161032.png]]
The steps for onboarding:

1. Click the "Add Schoology account" button
2. Enter the subdomain ( `https://<subdomain>.schoology.com`) that you use
3. WebView navigates to `/api`, user must paste in API keys to the application
4. WebView navigates to `/calendar`, user must find their calendar `webcal://` URL and paste it
   - This powers the dashboard, as a normal URL feed would be too unreliable
5. (Webview secretly grabs session cookies from the authenticated session, this powers notifications)
6. Importing begins
