Made an updater that basically updates the app by itself using `cargo-packager-updater`.

It was actually fairly simple. 

```rust
pub fn check_update() -> anyhow::Result<bool> {
    let config = Config {
        endpoints: vec![Url::parse(
            "https://github.com/orangishcat/foam/releases/latest/download/latest.json",
        )?],
        pubkey: include_str!("foam.key.pub").into(),
        ..Default::default()
    };

    let current = Version::parse(env!("CARGO_PKG_VERSION"))?;
    if let Some(update) = cargo_packager_updater::check_update(current, config)? {
        update.download_and_install()?;
        Ok(true)
    } else {
        Ok(false)
    }
}
```

As it turns out, the updater already handles all the metadata checking, and a simple `download_and_install` function replaces the binary perfectly.
