Finalized the type system. First we have Schoology API response format defined as a type, then we have it converted to standardized types that only contain the fields that the app needs to run.

So glad Rust has the `?` operator. Imagine if at each step, the `Result` had to be unwrapped by an if statement.

```rust
let json_response = API_CLIENT
        .as_ref()
        .map_err(|error| io::Error::other(error.to_string()))?  // <--
        .read()
        .map_err(|_| io::Error::other("API client lock is poisoned"))? // <--
        .get(url)
        .header(ACCEPT, "application/json")
        .header(AUTHORIZATION, authorization)
        .send()? // <--
        .error_for_status()? // <--
        .json()
        .map_err(Into::into)
```

The errors as return values thing is the main reason I haven't tried Golang and don't really want to. I get that this is an intentional design decision, but it seems like a terrible way to do control flow.
